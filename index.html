    Koneksi Roblox
    Belum terhubung ke Roblox
    Login Google dulu untuk mengisi User ID dan API Key.
    Roblox API Key
    Wajib diisi. Tersimpan hanya di perangkat ini (localStorage) dan dikirim ke endpoint Roblox lewat server saat upload.
    User ID Roblox
    Creator Type
    Group ID (Komunitas)
    Wajib diisi kalau Creator Type = Group. Asset akan dipublish atas nama Group ini, bukan akun pribadi — pastikan API Key dibuat dari Group tersebut (atau akunmu adalah member Group dengan izin Manage Assets) dan scope Assets: Read & Write dicentang.
    Cara mendapatkan Roblox API Key
    1. Buka create.roblox.com
    2. Klik Credentials di sidebar
    3. Create API Key, lalu centang Assets: Read & Write
    4. Salin key-nya ke kolom API Key di atas
    5. Mau publish ke Group/komunitas? Saat bikin API key, ganti "Owned by" ke Group tujuan (bukan akun pribadi), lalu isi Group ID-nya di bawah dan pilih Creator Type Group
    Hapus data Roblox
    Menghapus API Key, User ID, dan avatar dari perangkat ini.
